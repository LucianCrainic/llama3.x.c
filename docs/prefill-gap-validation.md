- Each directory holds small files: JSON reports, logs, logits hashes.

## Deviations

1. **`make test` inside the stage A/B jobs** (5892371 and 5892377) exited 2. They ran on a two-HBM-node host without socket binding, so the runtime tests that need one socket failed: "LLAMA_SOCKETS unset: both sockets have an HBM node". This is an environment effect, not a regression. The same suite passed with the campaign's socket-0 binding in job 5892384 (f6713ca) and is repeated in 5892424 on the final tree. Later stage jobs set `SKIP_TESTS=1`.
2. **Test fixes after the promotion.** 870a803 made AMX-BF16 attention and the vector SwiGLU exponential the W8A8 defaults. The local suite then failed tests that bound the GEMM or the tensor-parallel split against exact paths: the attention and the exponential changed the rounding, not the GEMM.
   - **Pinned to the ways back** (`LLAMA_ATTN=tiled`, `LLAMA_SWIGLU_EXP=libm`):
     - `tests/q8_engine.c` (66d9d27);
     - `test_tp`'s `test_amx_int8_two_socket_batched_prefill_agrees_with_one_socket` and `test_per_channel_int8_checkpoint` (522d940);
     - the scalar bitwise block of `tests/q8.c` (870a803). Its "vector exp" run keeps covering the vector exponential at the GEMM level on emulated AVX-512.
   - **Fixed.** `test_amx_bf16_attention_on_one_and_two_sockets` had compared `amx` against the default, which is now `amx`. It compares against `tiled` (c571ce5).
   - **New coverage of the default path** (c571ce5): `test_w8a8_defaults_take_amx_attention_and_vector_exp`.
     - It runs with no knob, on one and two sockets, at M = 5 and 32.
     - The default must equal `LLAMA_ATTN=amx` bitwise and the report must name `amx` and `vector`.
     - The budget against the ways back is the fixture's measured AMX-attention noise scaled by the W8A8 gate's headroom over the 8B defaults: rms ≤ 0.05 × 0.2 / 0.147 = 0.068 and max ≤ 0.25 × 16 / 9.4 = 0.43. Measured on the emulated tiles: rms 0.049, max 0.250.
     - Argmax agreement ≥ 0.9 counts near-ties within the max budget, the `assert_agree` convention. On this random 128k-vocabulary fixture the plain argmax agreement is 0.727.
   - The merge gate moved with each fix: 5892419 (23cac73) and 5892424 (66d9d27) were cancelled before they started, and so was 5892426 (522d940). Job 5892433 on c571ce5 failed on hardware (deviation 9); the rerun is 5892458 on 08d934c.
3. **The fix 7 attention phase counters** come from the wip tree (f8a7wip) with an uncommitted `LLAMA_ATTN_PROF` instrumentation. The committed kernel (5debcf4) is bitwise to the measured `amx3` variant (job 5892399, all 4 logits cells).
4. **The 5892385 gate predates 5debcf4 and bb817cf** and ran at M=256. Both commits are bitwise to the gated kernels (5892399, 5892400), and M is bitwise (5892402). The final defaults are gated again against Hugging Face on the batched path in job 5892459 (deviation 10).
5. **Two-socket decode** is 0.984 of develop in job 5892420. The decode path changed only by bitwise scheduling fixes, and same-tree runs differing only in a prefill knob show 0.988-0.994 (jobs 5892386, 5892387). This is read as run-to-run variation, not isolated.

9. **The merge gate failed on hardware** (job 5892433, c571ce5). The local suite runs `test_tp` without AVX-512 or AMX, so two tests never met the AMX-BF16 attention default there; the hardware run did. Jobs 5892451, 5892453 and 5892455 attribute the failures:
   - **`test_amx_bf16_attention_on_one_and_two_sockets`** held AMX attention on two sockets to one socket at the fixture tolerance (2e-6 + 2e-5 |a|). Measured: max 2.7e-3, on row 1 only; every other row within 7.2e-7.
     - The attention is partition-invariant. On hardware, 1 and 3 threads give bitwise the same logits on 1S and 2S. The new `tests/kernels.c` checks (b10ff98) hold one KV head per call, and any team, bitwise to the all-heads serial call.
     - Two sockets add the row-parallel Wo/W2 partial sums, which moves FP32 values by an ulp: tiled attention differs by 4.8e-7 between 1S and 2S. Such an ulp can flip one BF16 rounding of a Q or P element in the next layer.
     - The fix (08d934c) bounds 1S against 2S by the triangle inequality: |amx 1S − amx 2S| ≤ |amx 1S − tiled 1S| + |tiled 1S − tiled 2S| + |tiled 2S − amx 2S|. That is the test's existing AMX-against-tiled budget (max 0.5, rms 0.1). The median over rows of each row's worst difference must stay within the fixture tolerance, so a partitioning bug cannot hide in the envelope.
   - **`test_per_channel_int8_checkpoint`** compared the per-token path with the batched default. The AMX-BF16 prefill attention moved it by up to 0.31 on 1S and 0.32 on 2S; the SwiGLU exponential changed nothing. On tiled attention and libm the two paths agree within 1.4e-6 (1S) and 9.5e-7 (2S). The check compares an exact path, so 08d934c pins it to `LLAMA_ATTN=tiled` and `LLAMA_SWIGLU_EXP=libm`.
   - **The 0.05 + 0.02 |a| budget** of that test's chunk-against-batched check was set from local emulated runs (9ca3e7e), where the batched path runs the scalar kernels. On hardware, the scalar per-token path differs from the AVX-512 one by 1.05e-2 on this fixture (job 5892453). The budget is kept.
